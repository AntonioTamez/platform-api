## Person Identity

| Option | Description | Selected |
|--------|-------------|----------|
| Guid | String-friendly, no DB dependency, URL-safe, collision-proof | |
| int | Simpler, human-readable in URLs, requires DB auto-increment | ✓ |

**User's choice:** `int`, generated by Infrastructure (EF auto-increment), no value object wrapper.

**Notes:** User selected `int` for simplicity. The "Raw Guid" PersonId VO option was selected on the VO sub-question but interpreted as "no VO wrapper" since the ID type was already set to int. Decision recorded as: raw `int Id`, Infrastructure-generated, no wrapper type.

## Domain Error Contract

| Option | Description | Selected |
|--------|-------------|----------|
| Domain exception | throw new DomainException(...) — OOP, handled by Application via try/catch | ✓ |
| Result<T> (ErrorOr) | Railway-oriented, no exceptions in happy path, adds dependency | |

**Exception specificity:**
| Option | Description | Selected |
|--------|-------------|----------|
| One DomainException base class | Single type, Application catches by type, message carries detail | ✓ |
| Specific exception per rule | InvalidNameException, FutureDateOfBirthException, etc. | |

**Error message language:**
| Option | Description | Selected |
|--------|-------------|----------|
| English | Consistent with all-English codebase constraint | ✓ |
| Spanish | End-user readability | |

**User's choice:** Single `DomainException` class, thrown on any invariant violation, message in English.

## Value Objects vs Primitives

| Option | Description | Selected |
|--------|-------------|----------|
| Plain strings | FirstName, PaternalLastName, MaternalLastName as string — validation in Person.Create() | ✓ |
| Name value object | record Name(string Value) with self-enforcement | |

**DateOfBirth type:**
| Option | Description | Selected |
|--------|-------------|----------|
| DateOnly | Semantically correct, no timezone risk, EF Core 6+ native | ✓ |
| DateTime | More familiar but carries irrelevant time/timezone complexity | |

**Age exposure:**
| Option | Description | Selected |
|--------|-------------|----------|
| Computed property getter | public int Age => /* calculate */ — never stored | ✓ |
| Readonly field set in constructor | Simpler but stale after DateOfBirth updates | |

**User's choice:** Plain strings, DateOnly, computed property getter.

## Invariant Rules

**Name validation rules selected:**
| Rule | Selected |
|------|----------|
| Cannot be empty or whitespace | ✓ |
| Max length limit (100 chars) | ✓ (via "Standard" choice) |
| Min length limit (2 chars) | ✓ |

**DateOfBirth validation rules selected:**
| Rule | Selected |
|------|----------|
| Cannot be in the future | ✓ |
| No minimum age (newborns valid) | ✓ |
| Maximum age cap (150 years) | ✓ |

**Strictness:**
| Option | Description | Selected |
|--------|-------------|----------|
| Practical | Not-empty + max-length + DOB not in future. Shows pattern without over-engineering. | ✓ |
| Comprehensive | Regex, character whitelists, cultural name rules | |

**Concrete limits:** Standard — names: min 2 chars, max 100 chars. DOB: not in future, not older than 150 years.
